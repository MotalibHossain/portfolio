## 🚀 Quick Start

### 1. Install Dependencies
```bash
cd Portfolio_V2
npm install
```

### 2. Run Development Server
```bash
npm run dev
```

### 3. Open in Browser
Visit http://localhost:3000

### 4. Start Customizing
- Update your name in components
- Add your skills, projects, and experience
- Customize colors if desired
- Deploy to Vercel
